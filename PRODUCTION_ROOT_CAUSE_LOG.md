## Inference boundary

The browser microphone is the browser host's device. A microphone attached to DGX Spark is only usable when the browser runs on DGX with access to that device; Docker microphone passthrough does not make it available to a remote browser. The browser origin must be HTTPS or localhost for `getUserMedia`.
